# 板端RF接收机：完整工程与性能契约

本文件与USRP工程要求具有相同约束强度，不表示现有实现已完成。当前目标为ZedBoard/AD9361；迁移载板须重新验证电气接口、时钟、约束与驱动。

## 1. 完整交付与数据路径

交付必须包含可重建的RTL/IP/BD Tcl/XDC、仿真与综合实现脚本、时序/CDC/DRC报告、设备树、内核/驱动构建配置、PS服务、启动文件版本清单，以及安装/启动/停止/恢复说明与自动测试。bit、硬件描述、设备树、驱动和用户态ABI须匹配并记录哈希；单独bit流或一次成功日志不算完整工程。

```text
AD9361双路IQ → PL采集/CDC FIFO → 分块DMA/有界接收环
 → 同步/匹配滤波/定时/CFO与SFO处理/信道估计
 → MHGD任务批量化 → PL检测 → 批量结果校验
 → MRF两流header/payload CRC → RVF2重组 → H264解码
 → 有界视频输出接口 → 后续HDMI消费者
```

这是功能依赖图，滤波与同步的具体先后依已验证算法安排。每个边界须明确布局、计数单位、身份/时间戳、缓冲所有权、容量和异常行为。

## 2. 流水线与访问纪律

1. 连续采集、DMA、PS接收处理、PL检测和视频消费者必须重叠推进；禁止采满整段再离线解调，禁止显示或日志阻塞RF。
2. 禁止逐符号启动DMA、等待中断和读取结果。按RF帧或有界多帧批次提交检测任务；批次传输和完成处理摊销开销，唯一所有者读取结果后交付，禁止内外层重复读取。
3. 每RF帧有528个双流payload/CRC检测任务，header另行处理。预算须包含同步、估计、任务封装、DMA、检测、CRC、重组及解码，不能只报PL内核速度。
4. DMA/缓存所有权、一致性和生命周期须正确，避免不必要的整块复制/重新解析。必要的CRC、算法访问和缓存同步不得以“零复制”为由省略。
5. 时钟边界须有合法CDC、复位同步与经审查约束。RF输入不能任意背压：FIFO/环满须明确丢弃边界、溢出计数和恢复，不能静默覆盖未消费数据。
6. 所有队列有界。丢IQ块需通知同步器失连续；超时隔离旧批次；RVF2缺片不得输出残缺AU；预测链损坏等待独立IDR并计数。停止/ABORT须解除等待，DMA未停止不得释放缓冲。
7. 必测消费者阻塞、环满后恢复、短块、错序/重复、CRC失败、DMA错误、停止中断与重复启动。异常后不能把无效业务冒充有效数据。

流水线要求针对可重叠阶段，不否认真正的算法依赖；重复读取禁令针对重复I/O/解析，不禁止滤波、迭代或校验所需访问。

## 3. 吞吐与画质硬门槛

正式目标为1024×600、至少30个不同源视频帧/s，60为扩展目标。禁止重复帧、降低分辨率、循环IQ或以屏幕刷新率替代新视频帧率。画质需保存同源对比及编码参数，报告商定指标/视觉失真，不能只有fps。

本版4 MSPS、0.96 ms/RF帧，理想连续输入为1041.667 RF帧/s，仅payload/CRC就需550000个2×2检测任务/s；现有编码样例888 RF帧/s对应468864任务/s，尚未计入header及其他处理。不能由PL时钟直接推定达标。

冻结profile的RVF2有效片段上限1.666667 Mb/s，80%预算1.333333 Mb/s，尚有AU头/奇数片损耗。须先核算目标画质编码流，再测板端持续吞吐。若不足，提出收发双方版本化升级的采样率/帧效率/调制编码方案，并核算RF接口、DDR/AXI/DMA、CPU、DSP/BRAM/LUT、迭代数及完整时序；不能只提高USRP速率造成失配，也不能积压或牺牲未批准的画质冒充达标。

MHGD须在规定信道、SNR、CFO/SFO及定点范围验证正确率与吞吐。提高迭代数的成本计入预算；不得用浮点ZF/ML成功替代MHGD。当前混合信道局部搜索可靠性问题仍待解决，协议发布不豁免。

## 4. 集成与验收

先完成不依赖HDMI的USRP→AD9361→两流MRF CRC→RVF2→解码闭环，再接HDMI。视频消费者断开/阻塞不能造成无线接收无限积压。

离线须有向量、RTL单元/集成、DMA批次/停止/溢出恢复回归、可重复综合实现及完整时序/CDC证据。上板另测至少60秒连续运行和覆盖IDR及故障恢复的压力场景，记录：

- 实际采样率、频点、通道、CFO/SFO、增益、幅度/削顶及物理连接。
- ADC/FIFO/DMA错误、队列高水位、丢失/重复/错序、批次大小/调用次数、超时与恢复。
- 各阶段吞吐/耗时/阻塞、CPU/内存、任务率、MHGD正确性、两级CRC结果。
- 源→发送→接收→重组→解码身份账本、不同源帧率、丢帧、驻留及端到端延迟；跨设备延迟须说明时钟对齐，不能直接相减无关时钟。
- 同源图像质量、配置、全部失败及恢复；接入HDMI后另验显示新帧率。

编译通过、理想信道仿真或单帧上板成功均不能替代持续完整链路验收。
