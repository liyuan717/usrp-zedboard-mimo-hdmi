# USRP＋ZedBoard＋FMCOMMS3 原文件视频空口系统设计报告

提交基线：本机网页原 MP4、有限双流空口、ARM 接收前端、真实 PL 检测、完整文件恢复与 HDMI。日期：2026-11-04。RTL＋ARM C++/Python 实现，未采用 HLS 或 PYNQ。

## 背景与工程贡献

目标使用场景是实验教学、实验室无线文件/媒体链路演示与软硬协同验证。用户通过本机网页启动一轮有限测试，查看每一层真实结果，再在接收端 HDMI 观察内容；相较依赖模型逐条下发命令，操作入口和证据格式可由队员重复使用。原文件完整性是本版的优先指标，播放性能按实际物理回执披露。

目标是将电脑端有限视频通过 USRP 发射，经 FMCOMMS3 接收，在 ZedBoard 上恢复并显示，减少依赖模型逐条执行命令。项目内的主要改进是将已验证链路封装为受控网页操作，增加原文件分块/重组、独立证据核验、长捕获及显示隔离；不声称学术首创或已有文献之外的算法创新。已有工作与本作品贡献见 related_work.md；状态机/接口见 rtl_design.md，性能口径见 performance.md，历史失败保存于 sim/。

## 功能框图与划分

```mermaid
flowchart LR
  A[网页选择原 MP4] --> B[完整文件分块＋原 PHY]
  B --> C[电脑 UHD / USRP 双路发射]
  C -->|天线空口| D[FMCOMMS3 ADC / RXTH DMA]
  D --> E[ARM 同步、去直流、频偏与信道估计]
  E --> F[AXI DMA / PL 检测]
  F --> G[双流 CRC / 文件重组 / SHA]
  G --> H[ARM 解封装与视频解码]
  H --> I[DRM / HDMI]
```

电脑负责网页、固定操作编排、完整文件分块、波形及 UHD 有限发射；ARM 负责前端和文件/视频处理；PL 负责既有检测与 DMA/传输。现有 HDMI 拓扑使用 HP1，RF/RXTH/检测通路保留 HP0。软硬接口、寄存器/IRQ/设备树在源树、XSA、DTB 和相关 UAPI 中保存，不因本次打包改变。前端与检测不能用旧 IQ 或预存视频替代新空口验收。

## 综合、实现与时钟

依据相同已验收 bitstream 对应 routed DCP，器件 xc7z020clg484-1，Vivado 2025.2。

| 资源 | 使用/总量 | 比例 |
|---|---|---|
| LUT | 43781/53200 | 82.30% |
| FF | 48484/106400 | 45.57% |
| BRAM tile | 22.5/140 | 16.07% |
| DSP | 41/220 | 18.64% |
| I/O | 77/200 | 38.50% |
| BUFG | 9/32 | 28.13% |
| MMCM | 3/4 | 75.00% |

布线 WNS +0.160 ns、TNS 0、WHS +0.010 ns、THS 0、WPWS +0.264 ns。报告工作点：PS FCLK/总线 50 MHz、delay 200 MHz、HDMI 约 148.148 MHz、RF 接口约 16 MHz；实际运行的采样率/显示器 EDID 另由运行回执确认。不能将约束频率或 1/WNS 当作最大频率，也不能由 FPGA LUT 百分比推断空口失败原因。

综合阶段曾记录 LUT 47291；route 优化后 43781。二者是同次流程不同阶段的口径，不是独立算法加速前后对照。

## 优化与限制

ARM 原前端改进了重复扫描/训练计算及捕获生命周期，保留既有 MIMO/PL/CRC。历史不同实收轮的视频原生处理60.9818 秒与 23.9507 秒的记录只作每轮时间，不作为同 IQ 严格加速比；同 IQ 字节等价检查以源树/validation 报告为准。显示采用同 buffer 主动扫描、静默 UART 和低频停止轮询；优先级候选减轻过闪动，但历史仍有异常，不能宣称已确定唯一根因。

本次审计先发现旧 vendor 补丁脚本锚点及源码身份问题，最终从原始归档找回精确 vendor 树，102 条 vendor 输入和 18 项自有配方均匹配，详见 `source_closure.md`。ARM 接收程序在原目录及新恢复目录均重新编译为同一已验收 SHA；完整 Vivado 综合/实现未在本次重跑，不能宣称本次新构建 bitstream 已通过。已验收 bit/DCP/XSA 和原实板数据/显示证据独立保存。

| 历史优化对照 | 原接收核心 | 加速候选 | 口径 |
|---|---|---|---|
| 十 AU 原生接收处理 | 60.9818 s | 23.9507 s | 两次独立新 ADC，非同 IQ 严格加速比 |
| LUT | 43781 routed | 43781 routed | 该 ARM 优化未改变 bitstream；资源不随软件更换 |
| 文件/像素与 CRC 门禁 | 保留 | 保留 | 不能以速度替代正确性或视觉验收 |
